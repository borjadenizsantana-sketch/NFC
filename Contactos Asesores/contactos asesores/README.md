# Contactos asesores

Archivos vCard para abrir y guardar los contactos desde un llavero NFC.

## Archivos
- `ana-asesora-uso.vcf`
- `adrian-asesor-uso.vcf`
- `isabel-asesora-uso.vcf`

## Publicar en GitHub Pages
1. Sube estos archivos a la carpeta `contactos asesores` del repositorio.
2. Comprueba que GitHub Pages esté activado para el repositorio.
3. Prueba en Safari el enlace HTTPS directo de cada archivo.
4. Graba en cada etiqueta NFC un registro **URL/URI** que apunte al enlace directo del archivo `.vcf`.

Importante: los archivos contienen datos personales de contacto. Si los publicas en un repositorio público, cualquier persona que encuentre los enlaces podrá consultarlos. Comprueba los enlaces antes de grabarlos en los llaveros.
